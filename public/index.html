Grok Bot — xAI 的 Always-On AI Agent

一台属于你的云端电脑，24/7 替你干活

调研日期: 2026-09-16 产品状态: Beta 发布方: xAI

什么是 Grok Bot

Grok Bot 是 xAI 于 2026 年 8 月 11 日推出的 AI Agent 产品。与传统聊天机器人不同，每个 Grok Bot 拥有一台持久化云端电脑——可以打开浏览器、读写文件、跑终端命令、登录你的应用账号，然后 7x24 小时替你干活。你关掉笔记本电脑，它继续工作；需要你拍板的时候才来找你。

一句话理解

你可以像给同事发消息一样给 Grok Bot 派任务，它会记住你们的对话、学习你的偏好，用得越多越顺手。本质上是"一个有自己电脑的 AI 同事"。

核心能力

💻 云端电脑

每个 Bot 拥有独立屏幕，共享同一台持久化云电脑。浏览器、文件系统、终端一应俱全，关机也不丢状态。

🔗 原生连接器

Gmail、Google Calendar/Drive、OneDrive、Outlook、Teams、SharePoint、Salesforce 开箱即用，无需 API 开发。

🔧 MCP 支持

支持 Remote MCP Server 接入，通过 Settings 添加 Connector，可扩展任意工具链。

🤖 多 Bot 协作

多个 Bot 可以在群聊中互相传递任务、分配职责，实现 Agent Swarm 式的团队协作。

连接器一览

Gmail Google Calendar Google Drive OneDrive Outlook Microsoft Teams SharePoint Salesforce MCP Server (Remote)

没有连接器的应用？Bot 会直接通过浏览器操作网页（Computer Use），不过可能遇到 CAPTCHA 等限制。

需要注意的点

共享电脑：同一账号下所有 Bot 共享一台云电脑、文件系统和浏览器凭证。不同 Bot 之间不构成安全边界，不适合隔离敏感凭证。

Computer Use 限制：通过浏览器自动化操作网页时，可能被 CAPTCHA 或反自动化机制拦截。

仅 Remote MCP：目前只支持远程 MCP Server，不支持本地 MCP。

价格门槛高：最低 $120/seat/月，没有免费 tier，对个人用户不友好。

调研结论

  • Grok Bot 的"持久云电脑 + 多 Bot 协作"是目前 AI Agent 产品中最激进的形态
  • 原生连接器覆盖了主流办公套件，适合跨应用自动化场景
  • 价格偏高、Beta 阶段稳定性待验证，安全隔离机制不足
  • 实时 X 平台数据是独家优势，其他竞品无法复制
  • 编程能力与 Claude Code 接近，但开发者工具链生态不如 Claude
